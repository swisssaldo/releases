# SwissSaldo

Persönliche Finanzübersicht für Schweizer Kontoauszüge (camt.053). Läuft lokal auf deinem Windows-PC,
deine Bankdaten verlassen den Computer nicht.

Dieses Repository enthält nur die Installationsdateien. Der Quellcode ist nicht öffentlich.

## Installieren

1. Unter [Releases](../../releases/latest) die Datei `SwissSaldo-Setup-<version>.exe` herunterladen.
2. Ausführen (keine Administratorrechte nötig). Falls Windows «Der Computer wurde geschützt» meldet:
   **Weitere Informationen → Trotzdem ausführen**.
3. Beim ersten Start den Lizenzschlüssel eingeben, den du erhalten hast.

## Updates

SwissSaldo meldet neue Versionen selbst und installiert sie auf Knopfdruck. Deine Daten bleiben dabei erhalten.
